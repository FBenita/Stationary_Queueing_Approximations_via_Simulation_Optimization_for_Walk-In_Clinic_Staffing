# Assessing Stationary Queueing Approximations via Simulation Optimization for Walk-In Clinic Staffing under Time-Varying Demand

This repository contains the data, algorithms, and interactive artifacts for the paper "Assessing Stationary Queueing Approximations via Simulation Optimization for Walk-In Clinic Staffing under Time-Varying Demand".

The framework couples a custom Discrete-Event Simulation (DES) engine with multi-objective search algorithms to evaluate trade-offs between manpower costs, waiting times, and service levels.
